COMMAND DAY SECONDARY SCHOOL, IJEBU ODE - DEPARTMENT TEST
=========================================================

OPEN THIS FILE:   index.html      (double-click it; works offline and on the web)

FOLDER CONTENTS
  index.html            The test app. Loads its questions from the "questions" folder.
  questions/            One file per subject. Edit these in Notepad to change or add questions.
  department-test.html  A one-file copy of the same app with a small built-in sample
                        question set. Use it only if you need a single file to share.
                        Editing questions/ does NOT change this copy.
  images/command.jpg    Original school logo and background image.
  images/command-optimized.jpg
                        Smaller display copy used by both app pages; keep it beside command.jpg.

TO CHANGE: school name, teacher PIN (default 1234), timing -> open index.html in Notepad
and edit the CONFIG block near the top.

Keep index.html and the "questions" folder together in the same place.

STUDENT PRIVACY AND DATA HANDLING
  The app stores names, student IDs, classes, answers, scores and test timing in the
  current browser's local storage. It does not send that data to a school server.
  Teachers can export results to CSV. Results remain on the device until cleared
  from Teacher access or browser storage is removed; exported files are separate
  and must be retained and deleted securely.

  Before using this with students, the school must approve and publish its privacy
  policy, lawful basis, retention period, student/parent rights and designated
  privacy contact. The on-page notice is not legal advice or a compliance guarantee.
  The default teacher PIN is visible in the page source and is not secure; do not
  treat this offline prototype as suitable for confidential production use.
